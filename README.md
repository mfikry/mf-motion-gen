# MF Motion Gen

MF Motion Gen 2.0 is a Windows desktop application concept for importing, validating, previewing, and rendering HTML-based motion graphic projects.

**Status:** Foundation and architecture validation. Candidate technologies are not final decisions.

## Intended workflow
External authoring (initially Gemini AI Studio) → import → validate → preview/seek → render → export.

## Documents
- `PRD.md` — product scope, workflow, requirements, quality gates.
- `TECHNICAL_DESIGN.md` — candidate architecture, runtime contract, security, prototype.
- `ROADMAP.md` — gated development phases.
- `AGENTS.md` — implementation-agent rules.

This is a clean V2 repository. V1 remains separate and is not a code or architecture baseline unless explicitly approved.
